# `sealed/` — Trial Endpoint Atlas Reference Fixture vs. Blind Keys

- `sealed/key.json` is a **deterministic rule-vs-rule reference agreement fixture** generated by `tools/trial_atlas/consensus_audit.py` over the 50-study stratified census (seed `4711`). Its labels come from regular-expression rules, **not** from a blind human labeller. It is tracked only so offline self-checks (`check_atlas.py` and `test_consensus_audit.py`) can verify quote-span integrity and rule consistency without network access.
- **Real blind keys and handover sheets must never be committed to git.** Both `handover/` and every other path under `sealed/` (`sealed/*` except `key.json` and this `README.md`) are git-ignored. When drawing a blind labelling set for a person (`make_labelling_sheet.py`), write the sheet and the sealed key outside the repository (for example under `.lab-files`) or to an ignored path such as `sealed/blind-key.secret.json`.
