# Trial atlas: rule lexicon 0.3.1-draft

Status: proposed, written 2026-10-11. Implemented in `tools/trial_atlas/lexicon.json` as 0.3.1-draft, on the `atlas/frozen-census` branch, for review, with one matching mechanism added to `tools/trial_atlas/lexicon.py` (the description upgrade, below). No class was added, removed or renamed; the 37 class ids are unchanged.

Provenance: rules by `claude-opus-5-5`, from errors of 0.3.0-draft on a labelled development set. No model was called to write them. Counts come from a throwaway script, kept outside the repository, that tags each development entry with `lexicon.py`'s own `tag_entry`. Clinical statements marked T0 are from memory and unverified.

## The data used, and what was kept away

- **Development set only.** 758 labelled primary-outcome entries. Each label is the class ids a model council gave. Every rule change was tuned and measured on these entries only.
- **Not seen.** The held-out half and its labels were not opened. The maintainer measures that half.
- **The snapshot.** It was read only to count how many entries outside the development set a change moves. No labels exist there.
- **Untrusted text.** Registry wording was read as data. No registry sentence, trial id or sponsor name appears here or in the lexicon. Rule examples and tests use made-up or short generic phrases.

All counts below are **in-sample**: measured on the same entries the rules were tuned on. They show that each fix does what it was meant to, not how the lexicon will do on new entries.

## Rules of thumb kept from 0.3

- A rule names the positive form of a measure. A word plus a growing exclusion list is avoided. Where a short closed list was used (generic rating-scale names, time-anchor words), the rule note says so.
- Unlike concepts are never merged.
- One made-up phrase per behaviour. No list of trial-specific words.
- Where the council's labels disagree with each other on similar wording, the rule follows the class gloss, and this note says so.

## What changed, by rule

Two rules were added and 22 changed, and one matching mechanism was added (DU-01, under "The description upgrade"). Every changed rule keeps its id and carries a `changed` note that starts with `0.3.1-draft:`, with the 0.3.0-draft note kept after it. `test_lexicon.py` (`Lexicon031Test`) has a positive and a negative test for each.

### Patient-reported: named versus unnamed

| Rule | Change |
| --- | --- |
| PRO-06 (new, `pro_named_other`) | A named instrument written as a name: two to four capitalised words, with small joining words allowed, ending in Questionnaire, Inventory or Scale. It is case-sensitive. Rules that keep it narrow: <ul><li>One capitalised word is not enough (a Likert scale).</li><li>Generic rating scales stay unnamed: visual analogue, numeric or verbal rating, Likert, n-point.</li><li>The Cystic Fibrosis (CF) Questionnaire stays the CFQ-R.</li><li>A stool form scale is not a patient-reported instrument.</li><li>"Index" is not used, because body mass and lung clearance indexes share the word.</li><li>It is dropped when the entry names the CFQ-R, whose domains are themselves called scales.</li><li>It is dropped when the entry names physical activity, whose gloss already includes activity questionnaires.</li></ul> |
| PRO-02 (`pro_unnamed`) | Self-, parent-, caregiver- and participant-reported added beside patient-reported. PRO-06 now suppresses it in the same field. A generic "questionnaire" word next to a named one therefore no longer gives `pro_unnamed`. |
| SINUS-01, SINUS-02 (new) | The Sino-Nasal Outcome Test (SNOT-20, SNOT-22) is tagged `sinus_upper_airway` as well as `pro_named_other`. SINUS-02 matches the test's name, abbreviated or spelled out, case-sensitive. The rest is explained under "A decision that reverses 0.3.0". |

### Sputum as a sample

| Rule | Change |
| --- | --- |
| MICRO-03 | The bare word sputum names the sample, not the measure. It is now dropped when the entry names any other class (`suppressed_by_any_other_class`); before, only three listed classes dropped it. "Sputum expectorated" is excluded like "sputum expectoration". |
| PK-01 | Peak concentration (also in sputum or blood) added beside maximum concentration. "In the sputum" is accepted with the article. An area under the curve of glucose, insulin or C-peptide is no longer pharmacokinetics; the README lists this as a known limit. A serum concentration of inflammatory markers or biomarkers joins the existing biomarker exclusions. |
| PK-02 | "AUC" right after glucose, insulin or C-peptide is not pharmacokinetics. |
| PK-03 | Antibiotic and antimicrobial concentrations or levels added beside drug concentrations. |
| INFL-01 | Added: <ul><li>Counts of leukocytes or neutrophils in a named sample: with a count word, or as the whole measure. Cells that are only the sample for another test, such as phagocytosis or gene expression, do not count.</li><li>Polymorphonuclear (PMN) counts.</li><li>The neutrophil proteases proteinase 3 and cathepsin G (T0).</li><li>Leukotriene B4.</li><li>IL-1 written with a sharp s in place of beta, a common encoding slip.</li></ul> |
| INFL-02 | TNF directly followed by alpha (TNFα, TNF-alpha). The Greek letter is a word character, so the old pattern missed it. |
| SPUT-01 | "Sputum expectorated" as a quantity, but not "expectorated for a culture". |
| MICRO-01 | Bacterial colonisation, bacterial burden and colony counts added. |

### Other boundaries

| Rule | Change |
| --- | --- |
| ICM-01 | A short-circuit current or Ussing chamber counts as ICM only with a rectal or intestinal word in the same sentence (within 60 characters). |
| CFTRBIO-02 | Takes the bare short-circuit current or Ussing chamber, such as on nasal or cultured cells, as another direct CFTR measure. It gives way to ICM-01 when the context is rectal. |
| GI-01 | Pancreatic insufficiency counts only as an outcome. It no longer counts after "with", "have" or "having" (who was enrolled). The coefficient of nitrogen absorption is added beside the coefficient of fat absorption (T0: both are used in pancreatic enzyme trials). |
| LIVER-01 | The bare word "liver" is replaced by positive forms: <ul><li>"liver" followed by a disease or measure word: stiffness, disease, fibrosis, steatosis, fat, elasticity, size, biopsy, ultrasound, elastography and the like;</li><li>such a measure "of the liver";</li><li>"fatty liver".</li></ul> A sentence about what the liver secretes or stores no longer counts. |
| HCU-01 | Changes: <ul><li>A hospitalisation used as a time anchor no longer matches (during, after, before, following, at, on).</li><li>A single antibiotic course or clinic visit counts only with a count word (number, frequency, rate, need for, time to). Plural "courses" and "clinic visits" still count.</li><li>A field that says "exacerbation requiring" gives no healthcare-use tag (`suppressed_by_pattern`), because that is the exacerbation's definition. A composite of an exacerbation or a hospitalisation keeps both tags.</li></ul> |
| SURV-01 | The survival of cells or bacteria (cell survival, survival against apoptosis) is not a patient outcome. |
| SURV-04 | The bare word "graft" was removed. Graft survival still matches through SURV-01. On the snapshot this moved no entry's classes; it only stops a weak rule from deciding. |
| SPIRO-01 | Added: <ul><li>FEF50 and FEF75;</li><li>maximal expiratory flow at 25, 50 or 75 percent (MEF, MMEF);</li><li>vital capacity, slow or inspiratory.</li></ul> A named spirometric measure beside vague lung-function wording now drops the vague tag. LUNGFN-V1 itself was not changed; its suppression list already covers `spirometry_other`. |
| SPIRO-02 | "Forced expiratory manoeuvres", in either spelling, added as a word for the spirometry method. |
| OXS-01 | Nitrotyrosine without the final e, and the activation or activity of Nrf2 (T0: the regulator of the antioxidant response). |
| FEAS-01 | The misspelling "feasability". |
| FEAS-02 | "Use errors" removed: handling errors with a device are a human-factors outcome, not whether a study or treatment can be carried out. Leaving the study early ("discontinued the study", "study withdrawal") added beside attrition. Stopping the study drug is not matched. |

### A decision that reverses 0.3.0

0.3.0-draft tagged the SNOT-22 as a named instrument only, by analogy with the CFQ-R, which is never also tagged pulmonary. 0.3.1-draft tags it with both classes, for three reasons:
- **Both glosses describe it.** The sinus gloss is "sinus, nasal polyp or other upper-airway measures". The SNOT-22 scores sinus and nasal symptoms, so it is a sinus measure as well as a named questionnaire.
- **The council agreed every time.** It gave both classes on all 5 development entries that name the test.
- **The analogy does not hold.** The CFQ-R is a general CF questionnaire. The SNOT-22 is about one area.

The repository's own grounding targets already define the sinus class through the SNOT-22.

### The description upgrade (DU-01), added after the held-out check

**Why.** The maintainer measured the first version of 0.3.1-draft on the held-out half (283 entries, not seen here):
- Pooled precision rose from 0.837 to 0.870, and recall from 0.848 to 0.875.
- `pro_unnamed` still had 3 true and 12 false positives there.

Most of those 12 have the same shape as 4 development entries. The measure is generic ("quality of life", "satisfaction"), and only the description names the instrument. `lexicon.py` read the description only when the measure gave no class, so these stayed `pro_unnamed`.

**What changed.**
- `lexicon.json` declares the upgrade under `matching.description_upgrades`:
  - id `DU-01`;
  - `measure_classes: ["pro_unnamed"]` and `replaces: ["pro_unnamed"]`;
  - `description_rules`: CFQR-01, PRO-01, PRO-04, PRO-06 and SINUS-02.
- `lexicon.py` applies it when the measure gave classes, all of them in `measure_classes`. Then only the listed rules are read on the description, with the usual suppression there.
- When one of them matches, the entry gets its class (`cfqr`, `pro_named_other`, or `sinus_upper_airway` for the Sino-Nasal Outcome Test) and loses `pro_unnamed`. The tag is marked `from_description`, with the exact span as for every tag.

**What it never does.**
- It never changes an entry whose measure named any other class.
- It never reads another rule on the description; general sinus words (SINUS-01) are not read there.
- It never changes how a measure with no class falls back to its description.

The loader refuses an upgrade that names an unknown rule or class, has no rules, or replaces a class it does not watch. Tests cover a positive, a negative, a measure that names another class, and the load checks.

**Effect.** On the development set it changes 4 entries, all toward the council's labels: 3 become `cfqr` and 1 `pro_named_other`. On the snapshot it changes 10 entries: those 4 and 6 others.

**Before and after for the classes it touches** (development set, in-sample, tp / fp / fn):

| --- | --- | --- | --- |
| pro_unnamed | 5 / 12 / 8 | 6 / 6 / 7 | 6 / 2 / 7 |
| pro_named_other | 19 / 0 / 23 | 33 / 0 / 9 | 34 / 0 / 8 |

## Rules not changed, and why

| Rule | Why it was left alone |
| --- | --- |
| PRO-03, PRO-05 (visual analogue scale) | The council called one visual analogue scale a named instrument. The `pro_unnamed` gloss and the PRO-03 note say a rating scale with no named instrument is unnamed, so the gloss is followed (the 0.3 proposal made the same call). |
| LUNGFN-V1 | Its errors came from three causes, none of them its pattern: <ul><li>A spirometric measure it did not know: fixed through SPIRO-01 and SPIRO-02.</li><li>A measure that names a safety outcome, whose description lists the spirometric values (3 entries). See the cross-field limit below.</li><li>Vague wording whose description names no measure.</li></ul> |
| LIVER-02 (CFLD) | One study registers "a test of CF liver disease" several times. The council gave glucose only to the glucose-test entry but imaging plus liver to the imaging entry. Making the abbreviation weak would fix the first and break the second, so it was left alone. |
| GI-01 "pancreatic enzymes" | The council called a question about which enzyme product was used before `other`, and an entry about enzyme intake gastrointestinal. The wording is too close to tell apart by rule. |
| FEAS-01 acceptability, usability, satisfaction | On the development set, acceptability is the council's feasibility class in 8 of 9 entries. The ninth is acceptability of an inhalation's taste, which the council read as tolerability, and it came from a description. Usability gave no false positive. Satisfaction is in PRO-02, not FEAS. No change. |
| MICRO-01 "microbiota" | The council called a gut-microbiota entry `other`. The class label is "Microbiology", not only airway microbiology, so this is a question for the clinician reader, not a rule fix. |
| BONE-01 and DXA alone | "DEXA results" with z- or T-scores in the description is a miss. DXA alone stays unused by design, because body composition by DXA is nutrition. |
| SPIRO-02, SPIRO-03 versus FEV1 | Two entries say only "spirometry" or "forced expiratory volume", and the council read them as FEV1. The lexicon never infers FEV1 from wording that does not name it. |

## Development entries still wrong that could not be fixed without over-fitting

- **Cross-field patient-reported entries: now fixed by DU-01.** The 4 development entries in this group (the measure generic, the instrument named only in the description) are now tagged with their instrument's class. A first idea, marking PRO-02 vague, was rejected: it would set the vague flag on every patient-reported entry and let the earliest class in any description win.
- **Cross-field safety and lung-function entries (3).**
  - What happens: a tolerability measure names "pulmonary function tests", and the description lists FEV1 and FVC.
  - Why rules cannot fix it: the measure named a class, so the description is not read. DU-01 deliberately does not cover this case.
- **The earliest-match fallback (5).**
  - What happens: in one study, the measure names only the sample collection. The description lists an oxidative marker first and an inflammation marker after it, and the council gave both classes.
  - What changed: the fallback keeps only the earliest description match. With nitrotyrosine now recognised, these 5 entries changed from inflammation markers to oxidative stress. Each class gained or lost 5 true positives; the total is unchanged.
  - What would fix it: keeping every class from the description's first sentence, which is a code change.
- **One study's repeated measure text (2).**
  - What happens: the measure text is identical across about a dozen entries. The council gave safety only to two of them, from their descriptions, and gastrointestinal plus safety to the rest.
  - Why rules cannot fix it: a rule cannot tell identical measures apart.
- **Single-entry wording (about 6).** Each would need a word fitted to one entry:
  - an in-house questionnaire with a lower-case name;
  - "sensation of throat irritation" read as patient-reported and safety;
  - "observance" (adherence) of a follow-up;
  - "graft colonisation" as microbiology;
  - primary graft dysfunction read as imaging and oxygenation;
  - "acute oxidation" with a mistyped ratio.

## Held-out measurement (added by the controlling agent after the rules were written)

The held-out half is the 283 rows of the census frozen set's sampled strata whose entry id hashes to an odd number (SHA-1 of the entry id, first 8 hex digits, modulo 2). The rule writer never saw their wording-to-label pairs. Unweighted, pooled over the specific classes, rules plus the consensus-filtered model proposals, scored against the council's labels (`other` and `not_stated` not scored):

| Lexicon | True positives | False positives | Misses | Precision | Recall |
| --- | --- | --- | --- | --- | --- |
| 0.3.0-draft | 252 | 49 | 45 | 0.837 | 0.848 |
| 0.3.1-draft | 265 | 35 | 32 | 0.883 | 0.892 |

On the development half (in-sample) the same figures went from 0.893 and 0.836 to 0.944 and 0.888. The gain on the held-out half is smaller than in-sample, as expected, and it is concentrated in the patient-reported boundary: `pro_named_other` 18 right and 20 missed became 29 right and 9 missed, and `pro_unnamed` false positives fell from 20 to 8. One class moved the wrong way, `inflammation_markers` (one more miss). These are measurements against model-council labels (tier T2), on one snapshot, and they do not say the classes are right in a clinician's eyes.

Because the sampled strata of the next frozen set are drawn with the development entries excluded (`make_labelling_sheet.py --sample-exclude`, checked by `check_atlas.py --frozen-exclude`), the gate's sampled-stratum numbers are also out-of-sample for these rules.
